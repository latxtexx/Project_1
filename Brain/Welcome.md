# AntiGrav Finance Vault

ศูนย์รวมเอกสารและข้อมูลการเงินของ AntiGrav ใช้ลิงก์ด้านล่างเพื่อเปิดดูภาพรวมระบบ คู่มือ การทดสอบ และสมุดรายรับรายจ่าย

## เอกสารระบบ

- [[plan|พิมพ์เขียวระบบการเงิน]] — โครงสร้างข้อมูล อัลกอริทึม และสถานะการพัฒนา
- [[manual|คู่มือ AntiGrav Cyber HUD]] — วิธีใช้งาน หน้าจอ และ Local Server
- [[test|บันทึกการทดสอบ]] — จุดเชื่อมโยงไปยังการทดสอบและเอกสารประกอบ

## ข้อมูลการเงิน

- [[รายรับรายจ่าย/README|สมุดรายรับรายจ่าย]] — ที่จัดเก็บรายการและยอดบัญชีใน vault

## เส้นทางความเชื่อมโยง

พิมพ์เขียวกำหนดรูปแบบข้อมูลและการคำนวณ → คู่มืออธิบายแอปและวิธีใช้งาน → การทดสอบตรวจสอบตรรกะทางการเงิน → สมุดรายรับรายจ่ายเก็บข้อมูลที่แอปบันทึก
