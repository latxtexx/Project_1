# AntiGrav Finance Vault

ศูนย์รวมความรู้ของ AntiGrav จัดเอกสารตามความสัมพันธ์ของหัวข้อ แล้วเชื่อมโยงแนวคิด สถาปัตยกรรม วิธีใช้งาน การตรวจสอบ และข้อมูลการเงินจริงเข้าด้วยกัน

## เอกสารระบบ

- [[architecture/plan|พิมพ์เขียวระบบการเงิน]] — แนวคิด โครงสร้างข้อมูล และอัลกอริทึม
- [[guides/manual|คู่มือ AntiGrav Cyber HUD]] — วิธีใช้งานหน้าจอและ Local Server
- [[testing/test|บันทึกการทดสอบ]] — วิธีตรวจสอบว่าระบบทำงานตามที่ออกแบบ

## ข้อมูลการเงิน

- [[รายรับรายจ่าย/README|สมุดรายรับรายจ่าย]] — ที่จัดเก็บรายการและยอดบัญชีใน vault

## เส้นทางความเชื่อมโยง

พิมพ์เขียวกำหนดข้อมูลและกติกาการคำนวณ → แอปนำกติกาไปแสดงผลและบันทึกรายการ → การทดสอบตรวจสอบผลคำนวณ → สมุดรายรับรายจ่ายเก็บข้อมูลที่แอปอ่านและเขียน

## แผนที่โค้ด

- `apps/cyber-hud/` — เว็บแอปแบบ Standalone ที่เปิดผ่าน Local Server
- `src/` — Dashboard และโมดูล TypeScript สำหรับ Analytics กับชนิดข้อมูล
- `server/` — Local HTTP Server เชื่อมหน้าเว็บกับข้อมูลใน vault
- `supabase/` — โครงสร้างฐานข้อมูลและ migration
- `tests/` — ชุดตรวจสอบการคำนวณ
