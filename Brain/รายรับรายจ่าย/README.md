# รายรับรายจ่าย

โฟลเดอร์นี้เก็บข้อมูลธุรกรรมและยอดบัญชีของ AntiGrav โดยเซิร์ฟเวอร์จะบันทึกข้อมูลลงใน [finance-data.json](./finance-data.json) เมื่อเพิ่มรายรับ รายจ่าย หรือโอนเงิน ข้อมูลจะถูกโหลดกลับเมื่อเปิดหรือรีเฟรชแอป

แอปยังเก็บสำเนาในเบราว์เซอร์เพื่อให้ข้อมูลยังอยู่เมื่อเปิดแอปโดยไม่มีการเชื่อมต่อกับเซิร์ฟเวอร์
